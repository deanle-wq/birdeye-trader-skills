# V3 workflow map

Skills own reusable capabilities and CLI commands. Workflows route a trader journey across those capabilities. A workflow is not sold or installed as a second copy of a skill.

| Starting question | Workflow |
|---|---|
| What is worth researching now? | `workflow-market-opportunity.md` |
| Is this token worth deeper research? | `workflow-token-due-diligence.md` |
| How does this wallet trade? | `workflow-wallet-analysis.md` |
| What are smart-money wallets doing? | `workflow-smart-money.md` |
| What changed since my last snapshot? | `workflow-monitoring.md` |
| What happened after this wallet sold? | `workflow-exit-rotation.md` |

Every workflow uses the smallest sufficient path and stops on invalid identity, unusable coverage or a breached call budget.
