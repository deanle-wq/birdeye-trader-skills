# Smart-money workflow

1. Use `birdeye-track smart-money` for broad discovery.
2. Use `birdeye-track smart-money-token` after the user names a token.
3. Use `birdeye-track kol` only with caller-supplied wallet addresses; do not invent a KOL directory.
4. Use `birdeye-wallet-analysis run` when the question changes from current activity to a wallet's behavior and track record.
5. Return feed membership and observed trades as evidence, not as an automatic copy signal.
